# Homeward Paws Planning Package

This package contains the approved planning baseline for the South African Android-first Homeward Paws application.

Start with:

1. `docs/00_HOMEWARD_PAWS_MASTER_BLUEPRINT.md`
2. `docs/CODEX_PROJECT_INSTRUCTIONS.md`
3. `docs/05_DEVELOPMENT_ROADMAP.md`

Detailed specifications:

- `docs/01_PRODUCT_AND_USER_FLOWS.md`
- `docs/02_SCREEN_AND_NAVIGATION_SPECIFICATION.md`
- `docs/03_SUPABASE_DATA_AND_RLS_PLAN.md`
- `docs/04_DESIGN_SYSTEM.md`
- `docs/06_TESTING_AND_ACCEPTANCE.md`

The `docs/visuals/` directory is reserved for the complete screen map and individual key-screen mockups.

This is a planning and development-context package. It does not yet contain application source code or final SQL migrations.
